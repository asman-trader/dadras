## 🛠️ فرآیند جمع‌آوری

### مرحله 1: دریافت متن

#### روش A: دانلود از سایت (ترجیحی)

```bash
# مثال: دانلود از qavanin.ir
wget https://qavanin.ir/Law/TreeText/123456
```

#### روش B: کپی دستی

1. باز کردن صفحه قانون
2. کپی تمام متن (Ctrl+A, Ctrl+C)
3. ذخیره در فایل `.txt` با encoding UTF-8

#### روش C: تبدیل PDF

```bash
# استفاده از pdftotext
pdftotext -enc UTF-8 input.pdf output.txt
```

### مرحله 2: آماده‌سازی فایل

#### ساختار فایل TXT مطلوب:

```
عنوان قانون - بخش/فصل
----------------------------------------

ماده 1:
ماده: [متن کامل ماده]
شرح: [توضیح]
مثال: [مثال 1] یا [مثال 2]
نکات کلیدی:
  - نکته 1
  - نکته 2
برچسب‌ها: #تگ1 #تگ2 #تگ3

ماده 2:
...
```

#### نکات مهم:

✅ **انجام دهید:**
- استفاده از encoding UTF-8
- شماره‌گذاری صحیح مواد
- حفظ ساختار و فرمت
- افزودن برچسب‌های مناسب

❌ **انجام ندهید:**
- استفاده از encoding نادرست
- حذف شماره مواد
- اضافه کردن محتوای غیرضروری
- ترکیب چند قانون در یک فایل

### مرحله 3: نام‌گذاری فایل

```
قانون-مدنی.txt
قانون-تجارت.txt
قانون-مجازات-اسلامی.txt
آیین-دادرسی-مدنی.txt
```

قالب: `نام-قانون.txt` (با خط تیره، بدون فاصله)

## 🔄 فرآیند تبدیل

## 🤖 ابزارهای کمکی

### 1. Web Scraper ساده

```python
import requests
from bs4 import BeautifulSoup

url = "https://qavanin.ir/Law/TreeText/123456"
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')

# استخراج مواد
articles = soup.find_all('div', class_='article')
for article in articles:
    print(article.get_text())
```

### 2. PDF Converter

```bash
pip install pdfplumber

python

...         print(page.extract_text())
```

### 3. Text Cleaner

```python
import re

def clean_law_text(text):
    # حذف فواصل اضافی
    text = re.sub(r'\s+', ' ', text)
    # نرمال‌سازی
    text = text.strip()
    return text
```
