## ✨ ابزارهای جدید

### 1️⃣ **law_parser.py** - پارسر هوشمند

```python
from tools.law_parser import LawParser

parser = LawParser()
articles = parser.parse_file('input.txt', 'civil_law', 'معاملات')
parser.save_to_json('output.json', articles)
```

**قابلیت‌ها:**
- ✅ تشخیص خودکار شماره مواد با الگوهای مختلف
- ✅ استخراج عنوان، متن، توضیح، مثال‌ها
- ✅ تولید خودکار تگ‌ها براساس محتوا
- ✅ پشتیبانی از encoding های مختلف (UTF-8, Windows-1256, ...)
- ✅ تمیزکاری و نرمال‌سازی متن
- ✅ تقسیم خودکار به chunk های قابل مدیریت

---

### 2️⃣ **batch_processor.py** - پردازش دسته‌ای

```bash
python batch_processor.py --auto
python batch_processor.py --config my_config.json
```

**قابلیت‌ها:**
- ✅ کشف خودکار فایل‌های TXT
- ✅ پردازش موازی (Parallel Processing)
- ✅ گزارش‌دهی کامل از نتایج
- ✅ به‌روزرسانی خودکار index.json
- ✅ مدیریت خطا و retry

---

### 3️⃣ **law_cli.py** - ابزار خط فرمان

```bash
# پارس یک فایل
python law_cli.py parse input.txt civil_law معاملات output/

# پردازش دسته‌ای
python law_cli.py batch --auto

# جستجو
python law_cli.py search "عقد"

# لیست قوانین
python law_cli.py list

# آمار
python law_cli.py stats

# اعتبارسنجی
python law_cli.py validate

# صادرات
python law_cli.py export civil_law output.json

# ایجاد قانون جدید
python law_cli.py create new_law "عنوان قانون"
```

**10+ دستور کاربردی!**

## 🛠️ فرآیند استاندارد

### 1. دانلود قانون

```bash
# از سایت معتبر
wget https://rc.majlis.ir/fa/law/show/123456 -O law.html

# تبدیل به TXT
# (دستی یا با ابزار)
```

### 2. آماده‌سازی

```bash
# بررسی encoding
file -i law.txt

# تبدیل در صورت نیاز
iconv -f WINDOWS-1256 -t UTF-8 law.txt > law_utf8.txt

# کپی به laws
cp law_utf8.txt data/laws/قانون-مدنی.txt
```

### 3. پردازش

```bash
cd data/laws_structured/tools

# پارس
python law_cli.py parse ../../laws/قانون-مدنی.txt civil_law مدنی ../civil_law/general
```

### 4. بررسی

```bash
# اعتبارسنجی
python law_cli.py validate

# آمار
python law_cli.py stats

# جستجو برای تست
python law_cli.py search "ماده 1"
```

### 5. Commit

```bash
git add data/laws_structured/
git commit -m "افزودن قانون X - Y ماده"
```
