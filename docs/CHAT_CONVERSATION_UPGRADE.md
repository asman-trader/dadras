## 🔧 تغییرات تکنیکال

### 1. متد `get_chat_acknowledgment()`

```python
def get_chat_acknowledgment(self, question_data: Dict, case_info: Dict) -> str:
    """تولید پاسخ تأیید برای چت"""
    if 'chat_response' in question_data:
        response = question_data['chat_response']
        response = response.format(
            client_name=case_info.get('client_name', 'شما'),
            assistant_name=self.assistant_name
        )
        return response
    return random.choice(self.acknowledgments)
```

### 2. متد `get_next_question()` - بازنویسی شده

**Signature قبل:**
```python
def get_next_question(...) -> Tuple[Optional[str], Optional[str], bool]:
    return (question_text, question_id, is_complete)
```

**Signature بعد:**
```python
def get_next_question(...) -> Tuple[Optional[str], Optional[str], bool, Optional[str]]:
    return (question_text, question_id, is_complete, chat_acknowledgment)
```

**ویژگی‌های جدید:**
- استفاده از `assistant_name` به جای `lawyer_name`
- تولید پاسخ تأیید برای هر سوال
- ترکیب تأیید + انتقال + سوال بعدی
- پیام‌های خطای چت‌گونه
