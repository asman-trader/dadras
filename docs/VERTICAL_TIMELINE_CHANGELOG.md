یک **تایم‌لاین عمودی هوشمند** در سمت چپ صفحه اضافه شد که:

- ✅ به صورت **ثابت** (fixed) در سمت چپ نمایش داده می‌شود
- ✅ وضعیت هر مرحله را با رنگ و انیمیشن نشان می‌دهد
- ✅ فقط برای **پرونده‌ها** فعال است

---

## 🆕 ویژگی‌های جدید

### 1️⃣ تایم‌لاین عمودی

**موقعیت:**
- Fixed در سمت چپ (راست در RTL)
- عرض: 220px
- فاصله از بالا: 80px

**مراحل نمایش داده شده:**
1. قبل از شکایت
2. ثبت دادخواست
3. بررسی اولیه
4. جلسه دادگاه
5. صدور رأی
6. تجدیدنظر
7. اجرای حکم
8. پایان پرونده

### 2️⃣ تشخیص خودکار مرحله

سیستم با تحلیل متنی `case_stage` مرحله را تشخیص می‌دهد:

```javascript
function detectCaseStage(caseInfo) {
  // تحلیل هوشمند بر اساس کلمات کلیدی
  // مثال: "پرونده در جلسه دادگاه" → court_session
}
```

**کلمات کلیدی:**
- "بسته/پایان" → پایان پرونده
- "اجرا" → اجرای احکام
- "تجدیدنظر" → تجدیدنظر
- "رأی/حکم" → صدور رأی
- "جلسه/دادگاه" → جلسه دادگاه
- "بررسی/ارجاع" → بررسی اولیه
- شماره پرونده موجود → ثبت دادخواست
- پیش‌فرض → قبل از شکایت

### 3️⃣ وضعیت‌های بصری

**مراحل گذشته (Completed):**
- ✅ نقطه سبز روشن
- ✅ تیک در نقطه
- ✅ متن سبز

**مرحله فعلی (Active):**
- 🟢 نقطه سبز با انیمیشن pulse
- 🟢 متن سبز bold
- 🟢 سایه نور نبض‌دار

**مراحل آینده (Pending):**
- ⚪ نقطه خاکستری
- ⚪ متن خاکستری

## 🔄 گردش کار (Workflow)

```
1. کاربر پرونده جدید ایجاد می‌کند
   ↓
2. startCaseIntakeWizard() فراخوانی می‌شود
   ↓
3. updateVerticalTimeline() → نمایش timeline با مرحله اولیه
   ↓
4. کاربر اطلاعات را وارد می‌کند
   ↓
5. خلاصه تکمیل می‌شود → timeline به‌روزرسانی می‌شود
   ↓
6. کاربر "تحلیل حقوقی" می‌زند
   ↓
7. analyzeCaseStatus() → timeline به‌روزرسانی می‌شود
   ↓
8. مرحله فعلی با انیمیشن pulse نمایش داده می‌شود
```
