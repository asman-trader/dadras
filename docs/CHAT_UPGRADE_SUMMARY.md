## 🧪 تست کنید!

```bash
# راه‌اندازی سرور
python app.py

# تست گفتگو
curl -X POST http://localhost:5000/case/conversation/next \
  -H "Content-Type: application/json" \
  -d '{
    "case_title": "مطالبه وجه",
    "case_info": {},
    "conversation_history": [],
    "user_answer": ""
  }'
```

**خروجی نمونه:**
```json
{
  "ok": true,
  "complete": false,
  "question": "⚖️ **سلام و درود!**\n\nمن **دادرس هوشمند** هستم...",
  "question_id": "greeting",
  "case_info": {}
}
```
