## 🚀 شروع سریع

### برای کاربران جدید:
1. ابتدا [راهنمای گفتگوی هوشمند](CASE_CONVERSATION_GUIDE.md) را بخوانید
2. سپس [راهنمای مدیریت پرونده](CASE_MANAGEMENT_GUIDE.md) را مطالعه کنید
3. برای درک تایم‌لاین، [راهنمای تایم‌لاین](VERTICAL_TIMELINE_GUIDE.md) را ببینید

### برای توسعه‌دهندگان:
1. تغییرات اخیر را در Changelogs بخوانید
2. کد را با راهنماها مقایسه کنید
3. برای افزودن ویژگی جدید، از ساختار موجود پیروی کنید
