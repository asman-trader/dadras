# 🚀 ارتقای سیستم مکالمه و تحلیل پرونده

## 📋 خلاصه تغییرات

سیستم مکالمه برای دریافت اطلاعات پرونده و تشخیص راه‌کارها به طور کامل ارتقا یافته است. این ارتقا شامل قابلیت‌های هوشمند و یکپارچه برای تحلیل جامع پرونده‌های حقوقی می‌باشد.

## ✨ قابلیت‌های جدید

### 1️⃣ سوالات تکمیلی هوشمند (Smart Questions)

**قبل:**
- سوالات ثابت و از پیش تعریف شده
- بدون توجه به نوع پرونده
- محدود به اطلاعات پایه

**بعد:**
```python
def get_smart_questions(case_info: Dict) -> List[str]:
    """
    تولید سوالات تکمیلی هوشمند با AI بر اساس:
    - نوع پرونده
    - محتوای شرح ماجرا
    - مرحله فعلی پرونده
    - مدارک موجود
    """
```

**مزایا:**
- ✅ سوالات متناسب با هر پرونده
- ✅ کمک به تکمیل اطلاعات مهم
- ✅ پشتیبانی از fallback بدون AI
- ✅ سوالات اولویت‌دار

### 2️⃣ تحلیل هوشمند با AI

**قبل:**
- تحلیل ساده بر اساس الگوریتم‌های ثابت
- بدون ارزیابی نقاط قوت و ضعف
- استراتژی‌های کلی و عمومی

**بعد:**
```python
def analyze_with_ai(case_info: Dict) -> Dict:
    """
    تحلیل هوشمند پرونده شامل:
    - نقاط قوت پرونده (3-4 مورد)
    - نقاط ضعف و ریسک‌ها (3-4 مورد)
    - استراتژی پیشنهادی (مختصر و کاربردی)
    - احتمال موفقیت (درصد با توضیح)
    - اقدامات فوری (3-4 مورد اولویت‌دار)
    """
```

**مزایا:**
- ✅ تحلیل تخصصی و دقیق
- ✅ شناسایی نقاط کلیدی
- ✅ استراتژی اختصاصی
- ✅ اولویت‌بندی اقدامات

### 3️⃣ تشخیص قوانین مرتبط

**قبل:**
- لیست کلی قوانین بدون جزئیات
- بدون ارتباط مستقیم با پرونده

**بعد:**
```python
def detect_relevant_laws(case_info: Dict) -> Dict:
    """
    تشخیص هوشمند قوانین شامل:
    - قانون اصلی مرتبط
    - 3-5 ماده مهم و کاربردی
    - توضیح مختصر هر ماده
    - مرتبط با محتوای پرونده
    """
```

**مزایا:**
- ✅ مواد قانونی دقیق و مرتبط
- ✅ توضیحات کاربردی
- ✅ پشتیبانی از قوانین ایران
- ✅ Fallback برای انواع مختلف

### 4️⃣ پیش‌بینی نتایج

**قبل:**
- بدون پیش‌بینی نتیجه
- عدم ارائه احتمال موفقیت

**بعد:**
```python
def predict_outcome(case_info: Dict, analysis: Dict) -> Dict:
    """
    پیش‌بینی نتایج احتمالی شامل:
    - احتمال موفقیت کامل
    - احتمال موفقیت جزئی
    - احتمال عدم موفقیت
    - بهترین سناریو
    - بدترین سناریو
    - توصیه نهایی
    """
```

**مزایا:**
- ✅ تصویر واقع‌بینانه از وضعیت
- ✅ آمادگی برای سناریوهای مختلف
- ✅ تصمیم‌گیری آگاهانه
- ✅ محاسبه امتیاز موفقیت

### 5️⃣ Endpoint تحلیل جامع

**قبل:**
- چندین endpoint جداگانه
- نیاز به فراخوانی چندباره
- عدم یکپارچگی

**بعد:**
```python
@app.post('/case/comprehensive-analysis')
def case_comprehensive_analysis():
    """
    تحلیل یکپارچه و جامع در یک فراخوانی:
    1. تحلیل وضعیت فعلی
    2. تحلیل هوشمند با AI
    3. تشخیص قوانین مرتبط
    4. پیش‌بینی نتایج
    5. پیشنهاد اقدامات
    6. سوالات تکمیلی
    7. چک‌لیست اقدامات
    """
```

**مزایا:**
- ✅ تحلیل کامل در یک فراخوانی
- ✅ بهینه‌سازی عملکرد
- ✅ کاهش ترافیک شبکه
- ✅ امکان غیرفعال کردن AI

## 🔧 تغییرات فنی

### فایل: `case_conversation.py`

#### توابع جدید:
1. **`get_smart_questions()`**
   - تولید سوالات هوشمند با AI
   - Fallback برای حالت بدون API
   - سوالات اختصاصی بر اساس نوع

2. **`_get_default_smart_questions()`**
   - سوالات پیش‌فرض بدون AI
   - تفکیک بر اساس نوع پرونده

### فایل: `case_manager.py`

#### توابع جدید:
1. **`analyze_with_ai()`**
   - تحلیل جامع با DeepSeek API
   - شامل نقاط قوت، ضعف، استراتژی
   - محاسبه احتمال موفقیت

2. **`detect_relevant_laws()`**
   - تشخیص قوانین و مواد مرتبط
   - استفاده از AI برای دقت بالا
   - Fallback با لیست پیش‌فرض

3. **`_get_default_laws()`**
   - قوانین پیش‌فرض برای هر نوع
   - نقشه قوانین ایران

4. **`predict_outcome()`**
   - پیش‌بینی نتایج با AI
   - ارائه سناریوهای مختلف
   - توصیه‌های حرفه‌ای

5. **`_get_default_prediction()`**
   - پیش‌بینی بر اساس امتیازدهی
   - محاسبه بر اساس مدارک و شرایط

### فایل: `app.py`

#### Endpoint‌های جدید:

1. **`/case/comprehensive-analysis` (POST)**
   ```json
   {
     "case_info": { ... },
     "include_ai": true
   }
   ```
   
   خروجی:
   ```json
   {
     "ok": true,
     "base_analysis": { ... },
     "checklist": [ ... ],
     "next_actions": [ ... ],
     "ai_analysis": "...",
     "relevant_laws": "...",
     "outcome_prediction": "...",
     "prediction_score": 75,
     "smart_questions": [ ... ],
     "summary": { ... }
   }
   ```

2. **`/case/smart-questions` (POST)**
   ```json
   {
     "case_info": { ... }
   }
   ```
   
   خروجی:
   ```json
   {
     "ok": true,
     "questions": [
       "سوال 1",
       "سوال 2",
       "..."
     ]
   }
   ```

#### Endpoint بهبود یافته:

**`/case/conversation/next` (POST)**
- اضافه شدن `smart_questions` در پاسخ نهایی
- اضافه شدن `next_step` برای راهنمایی
- یکپارچه‌سازی با سیستم تحلیل

## 📊 جریان کار جدید

### مرحله 1: جمع‌آوری اطلاعات
```
کاربر → گفتگو با وکیل هوشمند
      → دریافت سوالات
      → پاسخ‌دهی
      → استخراج اطلاعات
```

### مرحله 2: تکمیل گفتگو
```
اتمام سوالات → تشخیص نوع پرونده (AI)
              → خلاصه هوشمند (AI)
              → سوالات تکمیلی (AI)
              → آمادگی برای تحلیل جامع
```

### مرحله 3: تحلیل جامع
```
فراخوانی /case/comprehensive-analysis
    ↓
├─ تحلیل وضعیت فعلی
├─ تحلیل هوشمند AI
├─ تشخیص قوانین
├─ پیش‌بینی نتایج
├─ پیشنهاد اقدامات
└─ چک‌لیست اقدامات
    ↓
نمایش گزارش جامع به کاربر
```

## 🧪 نحوه تست

### تست با curl:

```bash
# تحلیل جامع
curl -X POST http://localhost:5000/case/comprehensive-analysis \
  -H "Content-Type: application/json" \
  -d '{
    "case_info": {
      "case_title": "تست",
      "case_type": "civil",
      "incident_description": "شرح تستی"
    },
    "include_ai": true
  }'

# سوالات هوشمند
curl -X POST http://localhost:5000/case/smart-questions \
  -H "Content-Type: application/json" \
  -d '{
    "case_info": {
      "case_type": "criminal",
      "incident_description": "شرح..."
    }
  }'
```

### تست با Python:

```python
import requests

# تحلیل جامع
response = requests.post(
    'http://localhost:5000/case/comprehensive-analysis',
    json={
        'case_info': {
            'case_title': 'پرونده تست',
            'case_type': 'family',
            'incident_description': 'شرح ماجرا...'
        },
        'include_ai': True
    }
)

result = response.json()
print(result['ai_analysis'])
print(result['relevant_laws'])
print(result['outcome_prediction'])
```
