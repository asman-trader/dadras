# 📋 به‌روزرسانی: نمایش عنوان در حالت Collapsed

## 🎯 خلاصه

در حالت جمع شده (collapsed)، هم emoji و هم عنوان نمایش داده می‌شود.

---

## 🔄 تغییرات

### قبل:
```
[📋]  ← فقط emoji
عرض: 48px
```

### بعد:
```
[📋 اطلاعات پرونده]  ← emoji + عنوان
عرض: 200px
```

---

## ✨ تغییرات CSS

### Timeline (روند دادرسی):

```css
/* قبل */
#verticalCaseTimeline.collapsed {
  width: 48px;
}
#verticalCaseTimeline.collapsed .v-timeline-title span:not(.emoji) {
  display: none;  /* عنوان مخفی بود */
}

/* بعد */
#verticalCaseTimeline.collapsed {
  width: 200px;
}
/* قانون display: none حذف شد → عنوان نمایش داده می‌شود */
```

### پنل اطلاعات:

```css
/* قبل */
#caseInfoPanel.collapsed {
  width: 48px;
}
#caseInfoPanel.collapsed .case-info-title span:not(.emoji) {
  display: none;  /* عنوان مخفی بود */
}

/* بعد */
#caseInfoPanel.collapsed {
  width: 200px;
}
/* قانون display: none حذف شد → عنوان نمایش داده می‌شود */
```
