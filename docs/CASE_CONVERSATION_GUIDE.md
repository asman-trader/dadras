# راهنمای سیستم گفتگوی هوشمند جمع‌آوری اطلاعات پرونده

## 📋 توضیحات

این سیستم یک گفتگوی انسان‌گونه با موکلین برای جمع‌آوری اطلاعات کامل پرونده‌های حقوقی ایجاد می‌کند. به جای استفاده از فرم‌های ساده، سیستم مثل یک وکیل واقعی با موکل صحبت می‌کند و اطلاعات را به صورت تدریجی و طبیعی جمع‌آوری می‌کند.

## 🏗️ معماری سیستم

### بخش Backend (Python)

**فایل: `case_conversation.py`**
- کلاس `CaseConversationManager`: مدیریت جریان گفتگو
- روش‌ها:
  - `get_next_question()`: تولید سوال بعدی بر اساس پاسخ‌های قبلی
  - `extract_info_from_answer()`: استخراج اطلاعات از پاسخ کاربر با استفاده از Regex
  - `finalize_case_info()`: ایجاد خلاصه نهایی پرونده
  - `generate_summary_text()`: تولید متن خلاصه برای نمایش

**فایل: `app.py`**
- Endpoint جدید: `/case/conversation/next`
  - متد: POST
  - ورودی: اطلاعات پرونده، تاریخچه مکالمه، پاسخ کاربر
  - خروجی: سوال بعدی یا خلاصه نهایی

### بخش Frontend (JavaScript)

**فایل: `templates/index.html`**
- تابع `startCaseIntakeWizard()`: شروع فرآیند جمع‌آوری اطلاعات
- تابع `startAIConversation()`: مدیریت جریان گفتگو
- تابع `askNextPythonQuestion()`: ارتباط با سرور برای دریافت سوال بعدی

## 🔄 جریان کار (Workflow)

### 1. ایجاد پرونده جدید
```
کاربر → دکمه "پرونده جدید" → انتخاب نوع پرونده → شروع گفتگو
```

### 2. جریان گفتگو
```
Frontend                    Backend
   |                           |
   |-- Request: شروع گفتگو -->  |
   |                           | تولید سوال اول
   |<-- Response: سوال 1 --     |
   |                           |
   | کاربر پاسخ می‌دهد         |
   |                           |
   |-- Request: پاسخ + سوال-->  |
   |                           | استخراج اطلاعات
   |                           | تولید سوال بعدی
   |<-- Response: سوال 2 --     |
   |                           |
   | ... ادامه تا پایان ...    |
   |                           |
   |-- Request: پاسخ آخر -->    |
   |                           | تحلیل نهایی
   |                           | تولید خلاصه
   |<-- Response: خلاصه --      |
```

### 3. نمایش خلاصه و ذخیره
- خلاصه کامل در چت نمایش داده می‌شود
- اطلاعات در localStorage ذخیره می‌شود
- اطلاعات در تاریخچه چت ثبت می‌شود
- دکمه‌های "ویرایش" و "تحلیل حقوقی" در دسترس قرار می‌گیرد

## 🎯 ویژگی‌های سیستم

### 1. استخراج هوشمند اطلاعات
سیستم با استفاده از Regex اطلاعات را از پاسخ‌های کاربر استخراج می‌کند:

**مثال - استخراج نام:**
```python
patterns = [
    r'(?:نام من|اسم من|من)\s+([^\n.،]+(?:\s+[^\n.،]+)+)',
    r'^([^\n.،]+(?:\s+[^\n.،]+)+)$'
]
```

**مثال - استخراج شماره تماس:**
```python
phone_match = re.search(r'09\d{9}|۰۹[\u06F0-\u06F9]{9}', answer)
```

### 2. شخصیت‌سازی وکیل
سیستم از نام‌های مختلف برای ایجاد حس شخصی‌سازی استفاده می‌کند:
```python
lawyer_names = [
    'دکتر محمد رضایی',
    'دکتر سارا احمدی',
    'حمید نوری',
    'فاطمه محمدی',
    ...
]
```

### 3. مدیریت خطا
- در صورت خطا در ارتباط با سرور، پیغام مناسب نمایش داده می‌شود
- تاریخچه مکالمه همیشه ذخیره می‌شود
- امکان ویرایش اطلاعات بعد از پایان گفتگو

### 4. ذخیره‌سازی چندگانه
- ذخیره در چت (سرور)
- ذخیره در localStorage (مرورگر)
- امکان export و دانلود

## 🔧 تنظیمات و سفارشی‌سازی

### اضافه کردن سوال جدید

برای اضافه کردن سوال جدید به فایل `case_conversation.py` مراجعه کنید:

```python
{
    'id': 'new_question',
    'question': 'متن سوال شما؟',
    'extract': ['field_name'],  # نام فیلد برای ذخیره
    'required': True,  # اجباری یا اختیاری
    'next_question': 'next_question_id'  # شناسه سوال بعدی
}
```

### تغییر متن خلاصه

متن خلاصه در متد `generate_summary_text()` قابل ویرایش است:

```python
def generate_summary_text(self, summary: Dict) -> str:
    text = f"""⚖️ **بررسی اولیه پرونده انجام شد**
    
    به عنوان وکیل مدافع شما، اطلاعات زیر را دریافت و ثبت کردم:
    ...
    """
    return text
```

### افزودن الگوهای استخراج جدید

برای بهبود استخراج اطلاعات، الگوهای جدید Regex را به متد `extract_info_from_answer()` اضافه کنید.

## 🚀 نحوه استفاده

### برای کاربران
1. بر روی دکمه "پرونده جدید" کلیک کنید
2. عنوان و نوع پرونده را وارد کنید
3. با وکیل هوشمند گفتگو کنید و به سوالات پاسخ دهید
4. پس از پایان گفتگو، خلاصه کامل را مشاهده کنید
5. در صورت نیاز، اطلاعات را ویرایش کنید
6. درخواست تحلیل حقوقی دهید

### برای توسعه‌دهندگان

**نصب:**
```bash
# فایل case_conversation.py در روت پروژه قرار دهید
# تغییرات در app.py و index.html اعمال شده است
```

**تست:**
```python
# تست مدیریت گفتگو
from case_conversation import CaseConversationManager

manager = CaseConversationManager()
case_info = {
    'case_title': 'پرونده تست',
    'case_type': 'civil',
    'created_at': '2025-01-01',
    'conversation_history': []
}

# دریافت اولین سوال
question, q_id, is_complete = manager.get_next_question(
    case_info,
    [],
    'پرونده تست',
    'دکتر محمد رضایی'
)
print(question)
```

**Debug:**
```python
# در app.py برای مشاهده لاگ‌ها:
app.logger.debug(f"Case conversation data: {case_info}")
```
