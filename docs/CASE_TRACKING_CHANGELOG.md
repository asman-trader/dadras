# 📋 تغییرات سیستم پیگیری کامل پرونده

## 🎯 خلاصه

سیستم **مدیریت و پیگیری کامل پرونده** اضافه شد که به کاربران اجازه می‌دهد:

- ✅ پرونده را از **ابتدا تا انتها** پیگیری کنند
- ✅ **اسناد حقوقی** (دادخواست، لایحه، دفاعیه) تنظیم کنند
- ✅ **تحلیل و استراتژی** حقوقی دریافت کنند
- ✅ **راهنمایی گام به گام** برای رسیدن به نتیجه مطلوب

---

## 📁 فایل‌های جدید

### 1️⃣ `case_manager.py`

**مدیریت کامل پرونده حقوقی**

#### ویژگی‌های اصلی:

- **تحلیل وضعیت پرونده** (`analyze_case_status`)
  - تعیین مرحله فعلی (قبل از شکایت، جلسه دادگاه، رأی، تجدیدنظر، اجرا)
  - اقدامات فوری
  - استراتژی پیشنهادی (تهاجمی/دفاعی)
  - تحلیل ریسک‌ها و فرصت‌ها
  - اقدامات بعدی

- **تولید اسناد حقوقی** (`generate_document`)
  - 📜 **دادخواست**: برای طرح شکایت
  - ⚖️ **دفاعیه**: برای دفاع از موکل
  - 📋 **لایحه**: برای تکمیل دفاعیات
  - 🔄 **تجدیدنظر**: برای اعتراض به رأی

- **تولید چک‌لیست** (`generate_checklist`)
  - لیست کارها برای هر مرحله
  - اولویت‌بندی (high/medium)
  - وضعیت (pending/in_progress/completed)

- **پیشنهاد اقدامات بعدی** (`suggest_next_actions`)
  - گام‌های مشخص بر اساس مرحله
  - اقدامات فوری بر اساس ریسک‌ها

#### مراحل پرونده پشتیبانی شده:

```python
'pre_complaint'    # قبل از شکایت
'complaint_filed'  # دادخواست ارائه شده
'court_session'    # جلسه دادگاه
'verdict'          # صدور رأی
'appeal'           # تجدیدنظر
'execution'        # اجرای احکام
```

## 🔧 تغییرات در فایل‌های موجود

### `app.py`

#### Endpoint های جدید:

##### 1. `/case/analyze` (POST)

تحلیل کامل وضعیت پرونده

**ورودی:**
```json
{
  "case_info": {
    "case_stage": "در دادگاه",
    "complaint_side": "شاکی",
    "case_type": "civil",
    ...
  }
}
```

**خروجی:**
```json
{
  "ok": true,
  "analysis": {
    "current_stage": {...},
    "urgent_actions": [...],
    "strategy": "...",
    "risks": [...],
    "opportunities": [...]
  },
  "next_actions": [...],
  "checklist": [...]
}
```

##### 2. `/case/generate-document` (POST)

تولید اسناد حقوقی

**ورودی:**
```json
{
  "doc_type": "lawsuit",  // lawsuit|defense|petition|appeal
  "case_info": {...},
  "additional_info": {...}
}
```

**خروجی:**
```json
{
  "ok": true,
  "document": "متن کامل سند...",
  "doc_type": "lawsuit"
}
```

### `templates/index.html`

#### توابع JavaScript جدید:

##### 1. `analyzeCaseStatus(caseId, caseInfo)`

تحلیل وضعیت پرونده و نمایش:
- مرحله فعلی
- استراتژی پیشنهادی
- ریسک‌ها و فرصت‌ها
- اقدامات فوری
- اسناد مورد نیاز

##### 2. `showActionPlan(caseId, caseInfo, actions, checklist)`

نمایش برنامه اقدام گام به گام:
- گام‌های مشخص
- چک‌لیست کارها با اولویت
- دکمه‌های دسترسی سریع

##### 3. `showDocumentMenu(caseId, caseInfo)`

نمایش منوی انتخاب نوع سند:
- دادخواست 📜
- دفاعیه ⚖️
- لایحه 📋
- تجدیدنظر 🔄

##### 4. `generateDocument(caseId, caseInfo, docType)`

تولید و نمایش سند حقوقی با قابلیت:
- کپی متن
- ویرایش و تکمیل با AI
- تولید سند دیگر

##### 5. `getDocTypeName(docType)`

تبدیل کد سند به نام فارسی

#### تغییرات در UI:

دکمه **"تنظیم اسناد"** اضافه شد به کنار دکمه‌های:
- ✏️ ویرایش اطلاعات
- 📊 تحلیل حقوقی

- قابلیت کپی مستقیم

## 📊 گردش کار (Workflow)

```
1. ایجاد پرونده
   ↓
2. گفتگوی جمع‌آوری اطلاعات (case_conversation.py)
   ↓
3. خلاصه اطلاعات + دکمه‌های عملیاتی
   ↓
4. [انتخاب کاربر]
   ├─→ تحلیل حقوقی (/case/analyze)
   │   ├─→ نمایش تحلیل کامل
   │   └─→ برنامه اقدام گام به گام
   │
   ├─→ تنظیم اسناد
   │   ├─→ انتخاب نوع سند
   │   ├─→ تولید سند (/case/generate-document)
   │   └─→ نمایش + کپی + ویرایش
   │
   └─→ ویرایش اطلاعات
       └─→ Modal ویرایش
```

## 💡 نمونه استفاده

### سناریو: تنظیم دادخواست

1. کاربر پرونده را ایجاد و اطلاعات را وارد می‌کند
2. بعد از خلاصه، روی "تحلیل حقوقی" کلیک می‌کند
3. سیستم تحلیل کامل را نمایش می‌دهد:
   ```
   ⚖️ تحلیل کامل وضعیت پرونده
   
   📍 مرحله فعلی: قبل از شکایت
   
   🎯 استراتژی پیشنهادی:
   • جمع‌آوری حداکثر مدارک
   • تنظیم دادخواست قوی
   ...
   ```

4. برنامه اقدام گام به گام نمایش داده می‌شود:
   ```
   📝 گام 1: تنظیم دادخواست با جزئیات کامل
   📎 گام 2: جمع‌آوری و مرتب‌سازی تمام مدارک
   ...
   ```

5. کاربر روی "تنظیم اسناد حقوقی" کلیک می‌کند
6. منوی انتخاب سند باز می‌شود
7. کاربر "دادخواست" را انتخاب می‌کند
8. سیستم دادخواست کامل را با تمام اطلاعات پرونده تولید می‌کند:
   ```
   ╔══════════════════════════════════════╗
   ║           📜 دادخواست                ║
   ╚══════════════════════════════════════╝
   
   ریاست محترم دادگاه...
   ...
   ```

9. دکمه‌ها برای کپی، ویرایش و تولید سند جدید نمایش داده می‌شود
